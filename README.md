# Portfolio Management System

### A Web-Based Application for Managing Professional Project Portfolios

A modern portfolio management application designed to help users create, organize, showcase, and manage their technical project entries through a simple and interactive interface.

Developed as part of the **DealerSetu Technologies Developer Internship Selection Exercise**.

---

## Project Overview

The application provides a centralized platform for managing portfolio entries. Users can maintain project information, highlight technical accomplishments, mention technologies used, and associate images with their projects.

The goal is to demonstrate practical web development skills, application functionality, and structured implementation of portfolio management operations.

## Key Features

- **User Authentication:** Login interface for accessing the application.
- **Portfolio Dashboard:** View and manage portfolio entries.
- **Create Entries:** Add project titles, categories, internship roles, and descriptions.
- **Image Management:** Upload project cover images.
- **Technical Accomplishments:** Highlight important project contributions.
- **Technology Tags:** Add and organize technologies used in projects.
- **View Entries:** Access saved portfolio information.
- **Update Entries:** Modify existing project details.
- **Delete Entries:** Remove portfolio entries when required.

## Installation & Setup

### Prerequisites
- Node.js
- npm

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Navigate to the Project

```bash
cd portfolio-management-system
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Open in Browser

```text
http://localhost:3000
```
